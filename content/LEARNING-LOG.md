# Content learning log

The memory of the content loop. The weekly routine READS this before
writing anything, and APPENDS a dated entry every Monday. Strategy
changes happen here, with evidence, or not at all.

## How the loop works

1. Monday, before drafting: pull last week's click data
   (`GET https://chat.crox.io/links/stats`, admin token) and any
   conversions (assessment submissions / contact forms / chat
   conversations in the crox-chat DB whose page_url or timing ties to
   a post window). Add any manual numbers Adam has supplied
   (impressions/reactions from LinkedIn's own analytics — the API
   cannot read these; Adam dictates them and they get committed here).
2. Score last week's test: what was the hypothesis, what happened,
   what's the decision (keep / kill / double down)?
3. State ONE new hypothesis for this week and write the posts to test
   it. One variable at a time — hook style, topic, sector, format,
   posting day — never several at once, or the result reads as noise.
4. Append the entry below. Newest first.

## Measurement notes

- Clicks per post are the primary automated signal (tracked links,
  tag convention `li-YYYYMMDD-slot`, e.g. `li-20260803-mon`).
- Conversions beat clicks: an assessment submission or inbound chat
  in the hours after a post is worth more than any impression count.
- Impressions/reactions are Adam-supplied and optional; never block
  the loop waiting for them.
- Small numbers are the norm. Judge direction over weeks, not single
  posts; only act on differences that repeat.
